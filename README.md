# Gestão de projetos aplicada ao WordPress

Repositório de materiais do Trabalho de Conclusão de Curso sobre a aplicação de práticas de gestão de projetos ao desenvolvimento com WordPress, no IFBA, Campus Vitória da Conquista.

O guia documenta a especificação proposta pelo estudo. A demonstração prevê que uma IA, no papel de desenvolvedora, aplique o guia a um briefing e produza um site e registros de gestão que possam ser conferidos.

| Pasta | Material |
| --- | --- |
| [documentos](documentos/) | Versões do artigo e do guia técnico. |
| [sites](sites/) | Arquivos do site do guia e dos sites de exemplo. |
| [execucoes](execucoes/) | Briefings, versões utilizadas, prompts, respostas, decisões e registros das operações. |
| [evidencias](evidencias/) | Capturas e relatórios de testes, acessibilidade, Lighthouse e SEO. |
| [resultados](resultados/) | Matrizes preenchidas, pareceres, análise e gráficos. |

## Organização das entregas

Use o mesmo identificador em todas as pastas da execução. Por exemplo, `CAT-001` pode identificar a primeira execução do catálogo fictício. Nos registros, vincule o requisito, o teste, a versão do guia e o caminho relativo da evidência correspondente.

Antes de adicionar arquivos, revise os dados para evitar publicar credenciais, tokens, cópias de bancos com dados pessoais ou capturas que exponham contas reais. Use dados fictícios no ambiente de demonstração.
